## FilmsUI - веб-приложение для редактировании фильмов
Позволяет через UI редактировать описание фильма, постер, ссылки, кто в ролях и т.д., выставлять дополнительные свойства (теги) со степенью применимости. Например: Драма 90% Смешной 80%
Использует FilmServices и FilmDb

Есть страницы фильмов и советов, справочники (актёры, жанры, режиссёры, страны, пользовательские свойства) с поиском и постраничным выводом, а также загрузка фильма по ссылке с Кинопоиска.
Загрузка с Кинопоиска разбирает HTML-страницу фильма. Если Кинопоиск отвечает антибот-страницей или меняет вёрстку, показывается понятная ошибка, а не падение приложения.

### FilmsServices
Содержит кучу инфраструктурного кода, а по сути просто связывает VM-модель с DB-моделью
Использует FilmDb и CommonRepositories

### FilmDb
Содержит DB-модель базы данных (фильмы и связанные справочники, завершающий вывод ЭС)
Содержит FilmDbContext. База данных - FilmsDb - подключение есть в FIlmsUI.
Содержит миграции БД 
Содержит репозитории
1. FilmRepository - взаимодействие с фильмом как с сильной сущностью и всех зависимых от нее справочников
2. AdviceRepository - взаимодействие с сущностью, представляющей собой совет, то есть рекомендацию, которую выдает ЭС
Использует CommonRepositories

### CommonRepositories
Инфраструктурные классы и интерфейсы для взаимодкействия с БД

### EsDb
Содержит модель и DbContext для БД с сущностями ЭС, такими как правило, консультация, цель вывода и т.д.
Подключается к базе данных EsDb
Использует CommonRepositories
Используется в EsUi


### ExpertSystemDb
Содержит модель базы данных и контекст БД, сгенерированные из edmx.
Содержит Dto для работы с классами БД.
Содержит класс DbWork для работы с БД.


## EsUi - WebForms-приложение для настройки ЭС и вывода
Подключается к собственной базе EsDb
Функция  "Синхронизировать"
1. Дело в том, что мы можем в UI редактировать советы как справочник
2. Далее, они должны попасть в ЭС в качестве домена значений (чтобы можно было указать вывод ЭС - ключ совета)
3. Эта синхронизация это и делает - берет значения домена советов из БД фильмов (FilmsDb) и сохраняет в EsDb
Также имеет возможность запукать консультацию - использует движок из EsConsultationServices.
Использует EsServices, EsConsultationServices, EsDb, CommonRepositories и FilmDb

## EsConsultationServices
Движок консультации и прикладная логика советов:
- `IConsultationService` — старт, текущий шаг, ответ, объяснение результата;
- хранение состояния консультации в EsDb;
- подбор фильма по совету и по фильтрам (`IFilmRecommendationService`);
- провайдер описаний советов для движка (`AdviceConsultationDisplayProvider`).

Не зависит от EsServices; используется и EsUi, и EsConsultationApi.
Использует EsDb, FilmDb, CommonRepositories

## EsServices
Содержит конвертеры, валидаторы, ViewModel и сервисы доступа к данным для EsUi:
редактор ЭС, каталог советов (`AdviceCatalogService`), справочники жанров
(`GenresService`) и свойств фильмов (`CustomPropertiesService`).
Бизнес-логики консультации здесь нет — она в EsConsultationServices.
Использует EsDb, FilmDb, CommonRepositories

## EsConsultationApi - HTTP API консультаций
ASP.NET Core Web API для прохождения консультаций ЭС «Фильмы»:
- `POST /api/consultations` — начать консультацию, вернуть `sessionId` и первый вопрос;
- `GET /api/consultations/{sessionId}` — текущий вопрос или результат;
- `POST /api/consultations/{sessionId}/answers` — ответить на вопрос;
- `POST /api/consultations/{sessionId}/another` — другой фильм по тому же результату;
- `POST /api/consultations/{sessionId}/review` — оценка «понравилось / нет».

На завершающем ответе возвращается результат-совет (GUID) и подобранный фильм.
Показанные фильмы сохраняются в EsDb (`ConsultationShownFilms`), поэтому «другой ответ»
не повторяется после перезапуска. Оценки пишутся в `EsDb.Reviews` (`10` / `0`).
Ошибки возвращаются как `ProblemDetails`: 400, 404, 409, 500.

Запуск:
```
dotnet run --project EsConsultationApi
```
В Development открывается Swagger (`/swagger`). Строки подключения `EsConnection`
и `FilmConnection` задаются в `appsettings.json`; экспертная система — секцией
`Consultation` (`ExpertSystemId` или `ExpertSystemName`, по умолчанию «Фильмы»).
Использует EsConsultationServices, EsDb, FilmDb



## WebApi - API для проведения консультации в VK
Содержит контроллер и методы для работы с ботом VK
Содержит реализацию команд для бота ВКонтакте для начала новой консультации, для отправки ответов пользователя в существующую консультацию.
Подключается к базе данных ExpertSystemDB
Использует ExpertSystemDb, Logic и VkBotLib

### VkBotLib
Библиотека базовых классов для создания ботов ВКонтакте
Базовые команды и клавиатуры

### Logic
Содержит различные классы с алгоритмами для различных целей
1. Реализация доступа к функциям ЭС (используется в ЭСForms и WebApi)
2. Логика проведения консультации ЭС (используется в ЭСForms и WebApi)
3. Сопоставление совета и имеющихся в БД фильмов - выбор наиболее похожих (используется в ЭСForms и WebApi)
4. Загрузка подробной информации о фильме по ссылке с кинопоиска (используется в FilmForms)
5. Загрузка и выгрузка пользовательских свойств (тегов) фильмов в Excel (используется в FilmForms) - занимает очень много времени
6. Синхронизация советов из справочника в значения для домена ЭС (используется в FilmForms и ЭСForms)


# Решение Utilities

## LoadFilms - утилита для загрузки фильмов в БД
Создана для массовой загрузки фильмов из базы IMDB
Подключается к БД Экспертной системы
1. Читает файл MovieLens movies.csv в формате id,title(год),жанр|жанр. Заносит в IMDbLoading (англ. название, год, англ. жанры)
2. Читает tags.csv в формате userId,movieId,тэг,timestamp. Готовит справочник тэгов. Считает количество упоминаний каждого тэга, сохраняет в файл (через SaveFileDialog) только тэги с числом упоминаний > 100
3. Читает links.csv в формате movieId,imdbId,tmdbId. Находит фильмы по DataSetID и проставляет им IMDb ID
4. Читает titles_tu.tsv вида tt[ID]\t[русск.название], проставляет русские названия
5. Читает tags.csv, считает повторы тэгов по каждому фильму, сохраняет в EnglishTags в формате тег(кол-во)|тег(кол-во)
6. Запрашивает RapidAPI IMDb и заполняет актёров, страны, режиссёров, постер, описание, рейтинг
7. Переводит английские описания на русский через API перевода RapidAPI (KiaraTranslate)
8. Читает Excel-файл со словарём англ-рус. тэгов и переводит EnglishTags в RussianTags
9. По встроенному словарю переводит англ. жанры в русские
10. Формирует из готовых записей IMDbLoading сущности Film, Actor, Country, Producer, Genre, FilmCustomProperty (веса свойств) и сохраняет в БД
Исходные данные для загрузки можно брать из MovieLens - https://grouplens.org/datasets/movielens/

# Перенос функций FilmForms в FilmsUi

## Постановка

В решении есть проект `FilmForms` — старый WinForms-проект. Нужно перенести все его функции в проект `FilmsUi` (Blazor).

Сейчас часть функций уже перенесена: в `FilmsUi` можно смотреть список фильмов, карточку фильма, редактировать фильм (в том числе выбирать связи из справочников).

Однако нельзя редактировать другие справочники:

- жанры;
- актёры;
- советы;
- страны;
- пользовательские свойства (теги);
- производители (режиссёры).

Нужно всё это перенести в `FilmsUi`.

Также есть форма для загрузки фильма по ссылке с Кинопоиска — `frmFillFilmFromUrl`. Её тоже нужно перенести отдельным пунктом в меню.
